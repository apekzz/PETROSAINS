iPhone camera setup

The red warning appears if you skip step 3, or if you open the IP address instead of oneshot.local.

  1. If an old OneShot Inventory profile exists, delete it in Settings → VPN & Device Management, then tap install again.
  2. Tap Install trust profile, then Settings → Profile Downloaded → Install.
  3. Required: Settings → General → About → Certificate Trust Settings → enable OneShot Local CA.
  4. Tap Open camera dashboard. It must say oneshot.local, not 192.168…
